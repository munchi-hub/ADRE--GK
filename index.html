📝 Question Management

📚 Existing Questions

📥 Bulk Question Import

Add many questions at once instead of entering them one by one.

JSON format

Paste an array of questions. Each question can contain:

topic, study_set, question, option_a, option_b, option_c, option_d, answer, explanation, is_premium

Example: 

[
  {
    "topic":"History",
    "study_set":"Assam History",
    "question":"Example question?",
    "option_a":"Answer A",
    "option_b":"Answer B",
    "option_c":"Answer C",
    "option_d":"Answer D",
    "answer":"Answer A",
    "explanation":"Explanation here.",
    "is_premium":false
  }
]
CSV format

You can also upload a CSV file with these column names: topic, study_set, question, option_a, option_b, option_c, option_d, answer, explanation, is_premium
